comm.axisprofile
==============

This bundle implements all supported axisprofiles. In general, 'axisprofile' is an umbrella term which can mean one of the following:

* a axisprofile specified according to the IEC 61800-7 standard (CiA402, CIP Motion, PROFIdrive or SERCOS)


### Supported axisprofiles
This is a list of all currently implemented axisprofiles in this repository:

* Servo Drive Profile over EtherCAT (SoE)

* Canopen over EtherCAT (CoE)

### Supported operating systems and platforms
* Linux x86_64, aarch64
* Windows x64
